Bob ear

The Windows installer for Bob, the service that runs on each fleet worker machine. It reports usage pools and worker status to the digest, and includes the system-tray app that shows those figures. Install it on every worker machine.

Download sha256 Release notes

Jeeves

The Windows installer for Jeeves, the central service that runs the work queue, webhooks, and the web console at /jeeves. Install it on the hub machine that serves this site, not on the worker machines.

Download sha256 Release notes

Priority Agent

The Windows program used to work with Priority (forms, reports, and related tools). Download the latest build and run it on the PC where you do that work.

Download sha256 Release notes

airc

The Windows installer for airc, a remote console for operating fleet machines over the network. Install it on the machines that need that console.

Download sha256 Release notes
