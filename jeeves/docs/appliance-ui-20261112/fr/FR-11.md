# FR-11 Pool usage JSON

## Goal

A signed-in LAN client can read the pool numbers the systray already paints.

## Deliverables

- GET /api/pools, session required, LAN required.
- machines[] fields: id, remaining_pct, fuel_stale, reset_label.
- remaining_pct is a number or null. The value 0 stays 0. Null stays null and is never copied from another machine.
- copilot fields: remaining, state, reset_at, fetched_at, unlimited, used, max_recorded_usage. Omit the object when the digest has no Copilot pool.
- overage_gbp is a number or null.
- Every other digest field is dropped. No tokens and no seat email.

## Testable

- A fixture row with remaining_pct 0 is returned as 0. A fixture row with null stays null.
- A row that also carries a token-shaped field does not return that field.
- No session returns 401. A non-RFC1918 client is rejected.
