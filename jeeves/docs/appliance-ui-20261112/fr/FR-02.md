# FR-02 Bool settings are checkboxes

## Goal

Every bool setting is a tick box, and clearing it saves 0.

## Deliverables

- The settings renderer emits input type=checkbox for type=bool, with value 1 when the current value is truthy.
- The save script posts 1 when the box is checked and 0 when it is not.
- Secret fields that are left blank are still not written.
- Text inputs remain for str, int, and float.

## Testable

- For every SCHEMA key with type bool, the HTML contains a checkbox with that name.
- A fixture page with one unchecked bool posts {"value":"0"}.
- A blank secret input produces no PUT.
