# FR-14 Overspend line

## Goal

The pools page shows the systray overspend line only when the GBP amount is above zero.

## Deliverables

- When overage_gbp is greater than 0, GET /pools shows the word overspend, the pound sign, and the amount to two decimals.
- When overage_gbp is null, missing, or 0, that line is absent.
- The line is once per page, not once per machine.

## Testable

- Fixture overage_gbp 1.5 renders the overspend line with 1.50.
- Fixture overage_gbp 0 renders no overspend line.
- Fixture overage_gbp null renders no overspend line.
