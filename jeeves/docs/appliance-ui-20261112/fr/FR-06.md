# FR-06 Read-only queue JSON

## Goal

A signed-in LAN client can read the current queue as JSON with a small whitelist of fields.

## Deliverables

- GET /api/queue, session required, LAN required.
- Body: ok, unaccepted, accepted.
- Each row keeps only repo, task, id, and worker. worker comes from the stored worker field, else nick, else it is omitted.
- Other stored fields are dropped.
- The same secret-shape refusal used by status applies to this body.

## Testable

- A fixture queue with extra keys returns only the whitelist.
- No session returns 401. A non-RFC1918 client is rejected.
- An empty queue returns two empty lists and ok true.
