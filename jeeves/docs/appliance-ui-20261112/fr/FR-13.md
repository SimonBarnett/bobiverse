# FR-13 Copilot pool line

## Goal

The pools page shows the one account-wide Copilot line the systray shows.

## Deliverables

- The line uses the tray sentence: Copilot - N% left, with the reset and updated labels when the pool has them.
- A missing pool renders Copilot - unknown.
- A stale pool keeps the tray stale marker and still shows the last percent when the tray would.
- The line is on GET /pools, under the machine rows.

## Testable

- Fixture remaining 37 renders Copilot - 37% left.
- A payload with no copilot object renders Copilot - unknown.
- The line appears once, not once per machine.
