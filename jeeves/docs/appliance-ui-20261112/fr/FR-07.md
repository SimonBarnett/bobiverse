# FR-07 Queue page

## Goal

The current queue has its own page, separate from the settings table and the status counts.

## Deliverables

- GET /queue renders two lists: waiting and in progress.
- Empty copy is exactly "Nothing is waiting." and "Nothing is in progress."
- A row shows repo, task, and id, plus worker when the JSON includes it.
- The settings page links to /queue. Unauthenticated visitors get the login page.

## Testable

- Authed GET /queue returns 200.
- A fixture with one unaccepted row and zero accepted rows shows that row and "Nothing is in progress."
- Both lists empty shows both sentences.
- GET /queue without a session returns the login HTML.
