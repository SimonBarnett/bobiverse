# FR-03 Show defaults

## Goal

Each non-secret setting shows the default from the schema next to the control.

## Deliverables

- GET /api/settings includes default. Secret keys return an empty default.
- The settings HTML prints that default for every non-secret row.
- The current value stays editable. The default is not written into the control unless it is already the current value.

## Testable

- Rendered HTML for BOB_CODERABBIT_WAIT_MIN contains the default 12.
- Rendered HTML for GH_TOKEN does not contain a default secret, and the API default is "".
- A non-secret key whose current value differs from the default still shows both.
