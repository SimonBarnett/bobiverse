# FR-04 Group settings by use

## Goal

Settings are sections with a heading and a one-line description, not one flat table.

## Deliverables

- SettingSpec carries group, group title, and group description.
- The assignment is the Groups table in docs/feature-request-jeeves-appliance-ui-2026-11-12.md.
- Any SCHEMA key added later must set the same three fields or the gap test fails.
- The settings HTML emits one heading and one description per group, in that table's order.

## Testable

- A walk of SCHEMA finds zero keys with an empty group.
- The eight headings and eight descriptions appear in the settings HTML.
- Keys from two groups do not render inside the same section.
