# FR-12 Machine pool rows

## Goal

The appliance shows each machine's Grok remaining percent the way the systray row does.

## Deliverables

- GET /pools renders one row per machine from GET /api/pools.
- A non-stale number is shown as that percent. 0 is shown as 0, plus the text out of tokens.
- fuel_stale shows [stale] and does not show the percent.
- A null percent that is not stale shows n/a.
- reset_label is shown when present.
- An empty machine list shows No pool readings.
- The shell links to /pools. Unauthenticated visitors get the login page.
- The page does not draw Cursor spending-group bars.

## Testable

- Fixture remaining_pct 42 renders 42%.
- Fixture remaining_pct 0 renders out of tokens.
- Fixture fuel_stale true does not render the percent.
- Fixture remaining_pct null renders n/a.
- GET /pools without a session returns the login HTML.
