# FR-05 Dropdown when a setting lists choices

## Goal

A setting with a closed set of values renders a dropdown. Bools stay tick boxes.

## Deliverables

- SettingSpec.choices defaults to an empty tuple.
- The renderer emits a select when choices is non-empty and type is not bool.
- The current value is the selected option. A value outside the list is still shown as a selected extra option so a save does not silently change it.
- No current SCHEMA string, int, or float key is given invented choices. Paths, URLs, and seconds stay text inputs.

## Testable

- A fixture spec with choices ("a","b") renders a select and does not render a free text input for that key.
- A bool spec with choices still renders a checkbox.
- A walk of today's SCHEMA finds empty choices on every real key.
