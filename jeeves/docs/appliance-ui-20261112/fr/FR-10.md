# FR-10 Appliance doc matches the new URL and groups

## Goal

The chair doc tells the operator how to open the UI after this pack, and still keeps it internal.

## Deliverables

- jeeves/docs/jeeves-settings-appliance.md states the URL https://jeeves.ntsa.uk/.
- It lists the eight groups and says defaults and checkboxes are on the settings page.
- It says the queue is at /queue.
- It says pool percents, the Copilot line, and the overspend line are at /pools.
- It says the name is internal DNS only.
- It says not to publish the UI on bob.ntsa.uk or irc.ntsa.uk.
- It says the certificate is operator-supplied.
- It does not instruct anyone to create public DNS.

## Testable

- A doc test finds https://jeeves.ntsa.uk/ and does not find an instruction to browse :7701.
- The same test finds the internal-DNS sentence and the bob.ntsa.uk / irc.ntsa.uk refusal.
