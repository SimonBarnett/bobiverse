# FR-08 Shared shell and NTSA logo

## Goal

Login, settings, status, and queue share one header and the NTSA logo already stored in git.

## Deliverables

- GET /assets/ntsa-gut-logo.png returns the bytes of bob/tray/assets/ntsa-gut-logo.png and a PNG content type.
- Login, settings, status, and queue HTML include that image path.
- The header links Settings, Queue, Status, and Log out. The login card omits the log-out link and shows User name, Password, and Sign in.
- No new artwork.

## Testable

- The asset body equals the git file bytes.
- All four pages contain /assets/ntsa-gut-logo.png.
- The login page contains one account field (FR-01) inside the card.
