# FR-09 HTTPS on jeeves.ntsa.uk with no port

## Goal

Operators open https://jeeves.ntsa.uk/ . The settings process is not published on port 7701.

## Deliverables

- A front door on the chair host terminates TLS for that name and proxies to 127.0.0.1:7701.
- With the front door enabled, the settings process binds loopback only.
- Port 80 for that name redirects to HTTPS.
- The certificate is one the operator already has (thumbprint or store name in the chair doc). Do not run a public ACME client. Do not create public DNS.
- If the TCP peer is loopback, the LAN check uses X-Forwarded-For. Otherwise it uses the peer address and ignores the header.
- Non-RFC1918 clients are still rejected.
- Login HTML and the operator doc do not tell anyone to browse port 7701.

## Testable

- A loopback peer with X-Forwarded-For set to a public address is rejected.
- A loopback peer with X-Forwarded-For set to an RFC1918 address is accepted.
- A non-loopback public peer is rejected even if the header says an RFC1918 address.
- Rendered login HTML does not contain :7701.
