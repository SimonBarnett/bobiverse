Jeeves commands

Human-readable chair verbs for the shop. Settings login stays at /jeeves; this page is unauthenticated /jeeves/commands. Source of truth in-repo: common/scripts/chair_commands.py (COMMANDS) plus jeeves/docs/jeeves-commands.md.

Open settings login Markdown on GitHub
CommandWhoWhat it does
!help [cmd]anyoneShort command list from the chair (rate-limited).
!list [all|repo|fr|mrb|uat]anyoneQueue / work snapshot in focus order.
!filter ...anyoneAlias for !list with a filter.
!statusanyoneChair health, queue counts, roster, last resync.
!stuckanyoneList stuck/held open jobs from the stuck-job sweep (FR #5510).
!focus / !unfocusread: anyone; write: owner / ear / allowlistPrioritise or clear repos/items in the offer order.
!ignore / !unignore / !ignoredowner / earSuppress or resume a repo in the queue.
!assign <seat> <repo> FR|MRB|UAT|FIX <n>owner / ear (simon or bob-*)Hand a queued job to an idle seat (same gates as !bored).
!resyncowner / earForce roster refresh + GitHub FR/MRB merge-resync.
!sweep [#chan]owner / earRe-apply +h/+o privilege grants in a channel.
!recycle [machine|all]owner / earRoute a RECYCLE wire line; Bob ear executes host ops.
!build / !build n [version] [ref] [--tests-only] / !build status|cancel|dry-run|preflight|tests-only nowner / ear (ops)Numbered catalog BUILD (FR #4006 / #8490): bare lists catalog; n runs that entry's yml, exports pack artifacts, reinstalls on install/fleet. Example: !build 1 0.1.40.
!installtest <owner/repo> <version> [tag] / dry-runowner / ear (ops)Msiexec install-test pre-release MSIs + post-checks (FR #4026). Example: !installtest SimonBarnett/bobiverse 0.1.32.
!register <#channel|machine>+o/+h in #bobiverseChanServ REGISTER shop channel and add to roster. Example: !register ionos.
!unregister <#channel|machine> [confirm] / dry-run+o/+h in #bobiverseInverse of !register: ChanServ UNREGISTER, drop roster, PART shop. Example: !unregister dry-run ionos.
!pin / !unpinowner / earStamp or clear require_machine on a queue row.
!cleargiveupowner / earClear give-up / needs_human stamps for a job.
!startworker [agent|plan] [machine]verified owner / ear (Bob ear)Ear-side (not chair): queue a tray worker start on the target machine (t810u). Example: !startworker agent marchhare.
!bored / ACK / DONE / NACK / GIVEUPshop wireSeat readiness and job lifecycle (program posts !bored).
pinganyoneReply pong (no bang).
