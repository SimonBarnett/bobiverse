Webhooks & API index

Fleet digest (GET report) GET /bob/v1/report

Direction: in · Purpose: Public fleet digest JSON for TipForm, UAT, and operators.

Who calls it: Browsers, TipForm, chair health probes, fleet scripts.

Auth (named only): None. Open GET on Cloudflare front-door.

Request schema: No body. Optional query unused.

Response schema: JSON object: machines, jobs, fuels, chair fields (shape evolves; treat unknown keys as opaque).

Status codes: 200 OK; 503 when digest.lock is wedged (retry).

Retry / idempotency: Safe to retry. Idempotent read.

Rate limits: Cloudflare + reverse proxy only (no app per-IP GET quota).

Reachability: Public via https://bob.ntsa.uk (Cloudflare). Local :7700 also serves aliases.

Source: common/scripts/bobcallback.py, bobreport.py · Related: FR #149 / #174 / #2458

Status callback (POST report) POST /bob/v1/report

Direction: in · Purpose: TipForm / ear status merge, worker ops, shop-down.

Who calls it: Fleet TipForm and ears on registered machines.

Auth (named only): None. Machine id must appear on the Jeeves-published ChanServ roster (registered-machines.json). Stray X-Bob-Secret ignored.

Request schema: JSON object with op in {merge, delete-worker, shop-down, worker-*} plus machine fields. Legacy bodies without op are normalized.

Response schema: JSON ok / error; empty 204 on some ops.

Status codes: 200/204 success; 400 schema; 403 not on roster; 413 too large; 429 rate; 503 lock.

Retry / idempotency: merge is upsert-style; callers may retry on 503/429 with backoff.

Rate limits: Default 120/min per machine (env BOB_REPORT_RATE_PER_MIN).

Reachability: Public Cloudflare POST to bob.ntsa.uk; rewritten to BobCallback :7700.

Source: common/scripts/bobcallback.py · Related: FR #174 / roster gate
