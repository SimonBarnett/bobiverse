Webhooks & API index

Jira-style intake POST /bob/v1/jira

Direction: in · Purpose: Customer Jira webhooks into fleet intake/announce path.

Who calls it: Jira Cloud/Data Center webhooks.

Auth (named only): None shared Bob secret. Schema + size + rate gates.

Request schema: Jira webhook JSON (issue events). See jira_webhook.py.

Response schema: 202/200 JSON ok; 400 bad body.

Status codes: 200/202; 400; 413; 429.

Retry / idempotency: Jira retries; receiver validates schema.

Rate limits: Per-source limiter in jira_webhook / bobcallback.

Reachability: Public Cloudflare.

Source: common/scripts/jira_webhook.py · Related: FR #190

Redacted example

POST https://bob.ntsa.uk/bob/v1/jira
Content-Type: application/json

{"webhookEvent":"jira:issue_updated","issue":{"key":"EX-1"}}
