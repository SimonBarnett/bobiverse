Intake / harvest POST /bob/v1/intake

Direction: in · Purpose: File issues/FRs/skills/harvest lessons without gh on the box.

Who calls it: Report-BobiverseIntakeIssue.ps1, harvest, MONITORING, crash reporters.

Auth (named only): None. Open endpoint; schema + size + rate gates. repo=owner/name required.

Request schema: JSON: kind in {issue,fr,skill,harvest}, title, body, repo (owner/name required), optional idempotency_key.

Response schema: HTTP 202 with intake receipt JSON (id, queued flags). Never returns secrets.

Status codes: 202 accepted; 400 schema/missing repo; 413; 429. Offline clients queue locally and Flush.

Retry / idempotency: idempotency_key + existing intake/<id> PR dedupe. Safe to retry.

Rate limits: Per-source intake rate limiter (see intake.py).

Reachability: Public Cloudflare. Path is /bob/v1/intake (not /bob/v1/harvest).

Source: common/scripts/intake.py, bobcallback.py · Related: FR #3135 / #2595

Intake receipt probe (GET) GET /bob/v1/intake/{id}

Direction: in · Purpose: Lookup a prior intake id / health probe path.

Who calls it: Chair webhook health (jeeves-health-probe), operators.

Auth (named only): None.

Request schema: Path id only.

Response schema: 200/404 JSON or empty depending on id.

Status codes: 200 or 404.

Retry / idempotency: Safe GET.

Rate limits: Proxy only.

Reachability: Public Cloudflare (ARR rewrite of /bob/v1/intake*).

Source: common/scripts/bobcallback.py · Related: FR #1014 health probe
