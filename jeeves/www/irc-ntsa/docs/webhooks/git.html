GitHub git webhook POST /bob/v1/git

Direction: in · Purpose: GitHub delivery into the digest job queue. Handled: ping, push, issues, issue_comment, pull_request, pull_request_review, check_run, check_suite. Ignored with 204 (no enqueue): workflow_run and other unhandled events (CI state comes from check_run + resync).

Who calls it: GitHub repository webhooks (allow-listed owners).

Auth (named only): Optional HMAC-SHA256 via X-Hub-Signature-256 when BOB_GIT_WEBHOOK_SECRET_FILE or <BOB_CONFIG_DIR>/github-webhook.secret exists. No secret file = unsigned owner-gated contract. BOB_GIT_ALLOW_UNSIGNED=1 allows missing signatures only (invalid still 401). Owner allow-list via BOB_GIT_OWNERS (default SimonBarnett).

Request schema: GitHub webhook JSON + X-GitHub-Event / X-GitHub-Delivery; optional X-Hub-Signature-256=sha256=<hex>.

Response schema: 204 empty on accept/ignore; 4xx compact JSON {"ok":false,"error":"<fixed reason>"}; 503 {"error":"processing deferred"} + Retry-After.

Status codes: 204 accepted or ignored; 400 missing event/malformed JSON/missing repository; 401 missing/invalid signature (when secret configured); 403 owner not allowed; 413 body too large; 429 rate limited; 503 processing deferred.

Retry / idempotency: GitHub does not auto-retry failed deliveries (manual/API redelivery within ~3 days). 503 keeps the envelope pending for drain; chair !resync / hourly github-resync is the state fallback. IIS may return 502.3 while BobCallback is unbound during restart.

Rate limits: 120/min per repository (ignored events do not consume budget).

Reachability: Public Cloudflare. Never post git events to /bob/v1/report.

Source: common/scripts/bobcallback.py, gitclaim.py, copilot_dispatch.py · Related: FR #5170 / #4711 / #4955 / #7467
