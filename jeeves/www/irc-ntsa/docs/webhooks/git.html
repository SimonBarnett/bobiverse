Webhooks & API index

GitHub git webhook POST /bob/v1/git

Direction: in · Purpose: GitHub delivery into the digest job queue (issues, PRs, checks, comments).

Who calls it: GitHub repository webhooks (allow-listed owners).

Auth (named only): None shared secret. Owner allow-list via BOB_GIT_OWNERS (default SimonBarnett). Event must be accepted.

Request schema: GitHub webhook JSON + X-GitHub-Event / X-GitHub-Delivery headers.

Response schema: 204/202 accepted; 403 owner/event; 429 rate.

Status codes: 202/204 accepted; 400 bad JSON; 403 owner/event; 413; 429.

Retry / idempotency: GitHub retries deliveries; chair also !resync / hourly github-resync fallback.

Rate limits: 120/min per repository.

Reachability: Public Cloudflare. Never post git events to /bob/v1/report.

Source: common/scripts/bobcallback.py, gitclaim.py · Related: FR #5170 / #4711 / #4955
