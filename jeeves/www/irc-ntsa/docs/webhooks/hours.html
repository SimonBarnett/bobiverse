Hours create POST /bob/v1/hours

Direction: in · Purpose: Create a work-time entry for timesheet drafting.

Who calls it: Agents / operators posting partial work logs.

Auth (named only): None. Rejects obvious credential fields; never logs request bodies.

Request schema: JSON with idempotency_key, user, timing fields (see bobhours.py).

Response schema: JSON entry id / status.

Status codes: 200/201; 400 schema/credentials; 413; 429.

Retry / idempotency: idempotency_key required for create; safe retry.

Rate limits: Default 60/min (env BOB_HOURS_RATE_PER_MIN).

Reachability: Public Cloudflare.

Source: common/scripts/bobhours.py · Related: FR #3450

Redacted example

POST https://bob.ntsa.uk/bob/v1/hours
Content-Type: application/json

{"idempotency_key":"example-hours-1","user":"ExampleUser","minutes":30,"note":"example"}

Hours list / summary / export GET /bob/v1/hours

Direction: in · Purpose: List, day summary, or export hours entries.

Who calls it: Operators and timesheet tools.

Auth (named only): None.

Request schema: Query: user, from, to, date, format=csv|json, optional filters.

Response schema: JSON list/summary or CSV export.

Status codes: 200; 400 bad query.

Retry / idempotency: Safe GET.

Rate limits: Proxy only for GET.

Reachability: Public Cloudflare.

Source: common/scripts/bobhours.py · Related: FR #3450

Redacted example

GET https://bob.ntsa.uk/bob/v1/hours?user=ExampleUser&from=2026-01-01&to=2026-01-02
GET https://bob.ntsa.uk/bob/v1/hours/summary?user=ExampleUser&date=2026-01-01
GET https://bob.ntsa.uk/bob/v1/hours/export?user=ExampleUser&format=csv

Hours heartbeat / close / withdraw POST /bob/v1/hours/{id}/heartbeat|close|withdraw

Direction: in · Purpose: Heartbeat an open entry, close it, or soft-withdraw.

Who calls it: Agents holding an open hours id.

Auth (named only): None. Schema + rate gates.

Request schema: JSON body (close may include note); id in path.

Response schema: JSON status.

Status codes: 200; 400; 404; 429.

Retry / idempotency: heartbeat safe; close/withdraw are state transitions (retry carefully).

Rate limits: Shares hours write rate (60/min default).

Reachability: Public Cloudflare.

Source: common/scripts/bobhours.py · Related: FR #3450
