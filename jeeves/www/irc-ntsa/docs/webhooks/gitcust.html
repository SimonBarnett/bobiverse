Priority customer catalog GET /bob/v1/gitcust

Direction: in · Purpose: Read the customer and task catalog (kind sc, so, or wbs, free-text title, path).

Who calls it: Operators and Priority customer tooling.

Auth (named only): None. Open GET.

Request schema: No body.

Response schema: JSON {"customers":[...],"tasks":[...]}. Empty lists when nothing is registered.

Status codes: 200 JSON.

Retry / idempotency: Safe GET.

Rate limits: Proxy only.

Reachability: Public Cloudflare. IIS BobGitcustWebhook rewrites to the chair.

Source: common/scripts/gitcust.py, bobcallback.py · Related: FR #9982

Register a customer or task POST /bob/v1/gitcust

Direction: in · Purpose: Register a customer and/or a task subfolder. Metadata only; does not create folders.

Who calls it: Operators registering Priority customer or SC/SO/WBS task folders.

Auth (named only): None. Schema gate on the JSON body.

Request schema: JSON: customer (name), optional path, optional task {kind: sc|so|wbs, title, path, customer}.

Response schema: 202 or 200 JSON of the stored catalog. 400 on a bad body.

Status codes: 200 stored; 400 malformed or task_schema.

Retry / idempotency: Same customer name is not duplicated. Task identity is customer + path.

Rate limits: Same body cap as other BobCallback posts.

Reachability: Public Cloudflare. IIS BobGitcustWebhook.

Source: common/scripts/gitcust.py, bobcallback.py · Related: FR #9982
