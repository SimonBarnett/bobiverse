Webhooks & API

Human-readable documentation for inbound BobCallback routes on bob.ntsa.uk, local-only aliases, and outbound Jeeves wake/stall callbacks. Tested against route constants in bobcallback / bobhours (FR #6453).

Public HTTP base: https://bob.ntsa.uk. IRC stays on irc.ntsa.uk. No route requires a shared password; protection is schema, size, rate, roster, and owner allow-lists.
