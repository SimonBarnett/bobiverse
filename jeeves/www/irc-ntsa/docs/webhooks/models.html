Models catalog (GET) GET /bob/v1/models

Direction: in · Purpose: Fleet Weights agent rows plus CLI options catalog for the tray/forms.

Who calls it: Tray Weights form, Agents/Workers settings, operators.

Auth (named only): None.

Request schema: No body. HEAD returns empty body.

Response schema: JSON {"clis":{CLI:{models:{model:{contexts:{context:{efforts:[...]}}}}}},"agents":[{"agent","cli","model","context","effort"}, ...]} (BOB-01 / FR #8819 / FR #8820). clis from digest-home models-valid-combos.json; missing CLI yields models:{}; stale:true when selection model absent.

Status codes: 200 JSON; never invents secret fields.

Retry / idempotency: Safe GET.

Rate limits: Proxy only.

Reachability: Public Cloudflare via BobModelsWebhook rewrite when deployed.

Source: common/scripts/models_catalog.py, common/scripts/bobcallback.py · Related: FR #8707 / BOB-01 · FR #8819 · FR #8835 / BOB-05 · FR #9122

Models catalog (PUT) PUT /bob/v1/models

Direction: in · Purpose: Persist Weights full replace (BOB-02 / FR #8708 / FR #8819). Agent cli is read-only.

Who calls it: Tray Weights form (direct listener / allowlisted LAN peer).

Auth (named only): None (schema + peer allowlist).

Request schema: JSON agents rows; changing cli for a known agent returns 400.

Response schema: 204 when changed; 200 when unchanged; 4xx on schema/cli mutation.

Status codes: 204 / 200 / 400 / 403; public IIS rewrites GET|HEAD|POST (PUT stays direct/LAN).

Retry / idempotency: Idempotent full replace.

Rate limits: Peer allowlist; public proxy GET|HEAD|POST (FR #9224); PUT direct/LAN.

Reachability: Direct bobcallback / allowlisted LAN for PUT. Public Cloudflare BobModelsWebhook is GET|HEAD|POST (FR #9224).

Models refresh (POST) POST /bob/v1/models/refresh

Direction: in · Purpose: Rebuild per-CLI options catalog from grok/agent/opencode models listings (FR #8820).

Who calls it: Operators / tray refresh.

Auth (named only): Peer allow-list (BOB_REPORT_ALLOW) same as other POSTs.

Request schema: Empty body or {"clis":["grok","cursor","opencode"]}.

Response schema: 200 JSON {"clis":{cli:{"models":[...],"refreshed_at"}},"refresh":{cli:{"status":"refreshed|failed","added","removed","reason"}}}; failed CLI keeps prior catalog; selections unchanged.

Status codes: 200 refreshed; 400 bad_json/unknown_cli; 403 peer; 429 rate_limited; 503 catalog_unavailable/busy.

Retry / idempotency: Safe to retry; per-CLI fail-closed; second call inside 60s returns 429 with no change.

Rate limits: One attempt per CLI per 60s (in-memory; restart resets).

Reachability: Public Cloudflare via BobModelsWebhook (^bob/v1/models(.*)).

Source: common/scripts/models_refresh.py, common/scripts/models_catalog.py, common/scripts/bobcallback.py · Related: FR #8820
