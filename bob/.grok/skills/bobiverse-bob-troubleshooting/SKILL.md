# bobiverse-bob-troubleshooting

> **CAST IRON RULE - HARVEST AND FILE EVERYTHING (read this first, every time).**
> 1. ALWAYS harvest skills you learn and file EVERY issue / FR / bug / gap you find to the intake webhook in the
>    SAME turn. Never leave a finding unfiled, never "note it for later", never skip it because it is small.
> 2. File with the intake webhook (no secret or login needed; `POST https://bob.ntsa.uk/bob/v1/intake`; offline it is
>    queued locally and retried):
>    `.\scripts\Report-BobiverseIntakeIssue.ps1 -Repo SimonBarnett/bobiverse -Kind issue -Title "short title" -Body "what / where / evidence / fix"`
>    (`-Kind issue|fr|skill|harvest`; always pass an explicit `-Repo owner/name`).
> 3. BEFORE finishing ANY debugging session run the harvest step:
>    `.\scripts\Invoke-BobiverseHarvest.ps1 -Summary "what broke / what fixed it" -Lesson "one learned playbook line"`
>    then `.\scripts\Invoke-BobiverseHarvest.ps1 -Flush` to resend anything that was queued while offline.
> 4. Never put a token, password, SASL/NickServ secret, key or private hostname in a filing, a skill or a log.

Start with `bobiverse-fleet-ops` (health checks, hotpatch rules, known-failure table). Ear-specific lessons:

| Symptom | Diagnosis / fix |
|---|---|
| Ear restarts every 30-60 s (new `ircBob-stdout-*.log` files, repeated `GRANT +h`) | The watcher/tray kills any `irc_agent.py --nick Bob-*` whose command line lacks `--host`. `Start-Bob.ps1` now passes `--host <IrcHost>` and the MSI bakes `-IrcHost` into NSSM. Hand-fix on an old install: add `--host irc.ntsa.uk` in `Start-Bob.ps1`, `Restart-Service ircBob`. |
| `NICKNAME_RESERVED` / `sasl-fail 904` | `home\nickserv.password` does not match the registered account. Oper `NickServ PASSWD bob-<machine> <value from the file>`; never create a new GUID for a registered account; restart `ircBob`. **FR #3904:** after upgrade, empty `InstallRoot\home` with missing nickserv was invisible (no AppStdout). Check `<ai root>\bob\logs\stdout.log`; Install migrates from prior BobHome / `\.bobiverse` and fails MSI 1603 if it cannot; ear logs `NICKNAME_RESERVED` once (FR #5352: not a crash hook) and backs off 300s. |
| SASL never attempted | Missing/unreadable `nickserv.password` (BOM or ACL). The file must be one line, no BOM. |
| Ear Running but never joins (no 001); TLS ok | **FR #3904:** missing Ergo PASS (`config\ergo.password`) and/or `home\nickserv.password`. Bob resolves sibling `<ai root>\airc\config\ergo.password` / `jeeves\config\ergo.password` and seeds a local copy. Place PASS by hand if siblings are empty (issue #4). |
| Outbox lines not sent | Ear home outbox: BOM or a partial last line (no `\n`), or LocalSystem-ACL only so your user cannot append - use a user-writable home. **Seat** outbox: check `worker.log` for `outbox: sent`. The seat outbox is drained by move-aside every 0.5 s, has no `.pos`, and is normally empty — never treat an empty file as proof a DONE was already sent (FR #2876). |
| Ear joined but no ops | Shop not registered: Jeeves `!register <machine>`; then `!resync`. |
| Tray **Agent** / **Plan** click does nothing, or the seat vanished | Read `%LOCALAPPDATA%\Bobiverse\worker\logs\bob-worker-agent.log` and the tray log `%USERPROFILE%\.grok\long-running-background-tasks\watch_bob_tray.log` (`worker exe missing` = reinstall the MSI; exit 3 = IRC lost, the exe kills its own agent and ends on purpose; exit 5 = restart limit). Every click starts a NEW agent - never resume. Full table: `bobiverse-bob-worker`. |
| Worker seat vanished; parent unknown after exit | `parent_of` after `proc.wait()` is empty. FR #1643 captures create-parent at `start_agent`; bin refresh defers locked hashed exe delete (harvest #1678 / PR #1658). |
| Worker console waits for Enter after Jeeves inject (`relay: injected`) | Frozen `bob-worker.exe` pre-dates FR #1601 submit gap. Press Enter to unblock; rebuild exe + new Agent seat for the durable fix (harvest #1605). |
| Tray shows twice / wrong icon | Old installers left top-level `Bob Systray` links; the new installer keeps ONE Start Menu folder `Bobiverse` and deletes the rest. |
| Tray dies when the agent shell exits | It was started with `Start-Process`; use `Start-BobTray.ps1` (WMI create). |
| TipForm **Restart** vs ear-only recycle | Menu **Restart** -> Restart-BobTrayWatcher -> Start-BobFleetTray -ForceNew (restarts ircBob + relaunches tray). Ear-only: Start Menu **Restart ircBob** / scripts\\Restart-BobEar.ps1. Do not document TipForm Restart as calling Restart-BobEar.ps1 directly (drift fixed in FR #154). |
| VISION S3 departure announce missing on IRC (recycle / ForceNew) | **FR #2943:** TipForm ForceNew and `Restart-BobEar` must write departure to the **same IRC home** `Start-Bob` chooses for the service (`InstallRoot\home` under LocalSystem), never only `%USERPROFILE%\.bobiverse`. An undrained profile `outbox.txt` / leftover `depart-request.txt` is proof the announce never reached the ear. Align with `Watch-BobTray` Write-BobTrayIrcDepartureAnnounce (install home outbox + drain). Product fix tracked on FR #2943. |
| Autostart/ONLOGON killed seats on logon | Missing -SkipTidy on tray shortcuts. FR #1636: autostart uses -ForceNew -SkipTidy; TipForm **Restart** remains the tidy path (harvest #1663). Watchdog relaunch (Ensure-BobTrayRunning) also ForceNew+SkipTidy (FR #1642 / #1681). |
| TipForm stale `{nick}: {work}` while workers active | Callback flap and/or `Get-BobTrayHover` hung the poll thread so `tray-status.json` froze (FR #1553 / harvest #1562). Confirm `Sync-BobTrayStatusWorkersFromDigest` + non-UI timer on main (PR #1576); heal `:7700` with `Start-BobCallbackSupervised.ps1`; compare TipForm vs queue ACC / stuck_accepted. Never block worker refresh on hover. |
| TipForm empty while digest has seats | Peer merge blanked `working_on` without rolling `worker_list` (PR #1495) or nick-map ignored `.work` (PR #1555). Check export fields + `bobreport._roll_working_on`. |
| Seat-wrapper kill removed a diagnosing shell | Never `match Watch-BobTray` broadly; the filter is `-File ...Watch-BobTray.ps1`. |
| Ear joins then quits in seconds (NSSM restarts) | **FR #5196:** leftover `agent.quit.request` from a previous stop. The ear now ignores/deletes files written before process start or older than 90s. Delete the file under the ear home and restart `ircBob`. If NSSM event 1030 says AppDirectory unset, re-run `Install-Bob.ps1` (always sets AppDirectory to `InstallRoot\scripts`). |
| Service shows old code after MSI | NSSM path/params stale - re-run `Install-Bob.ps1`; check `<ai root>\bob\VERSION`. |
| Digest POST fails | Machine not on the roster Jeeves publishes, or `reportUrl` unreachable. `Assert-BobDigestWebhookLocal.ps1`; `GET https://bob.ntsa.uk/bob/v1/report` should be 200. |
| `GET https://bob.ntsa.uk/bob/v1/digest` returns 404 | Expected on the public IIS front-door (FR #149). Public digest JSON is `GET https://bob.ntsa.uk/bob/v1/report`. Local bobcallback on `:7700` still answers `/bob/v1/digest` and `/digest` with the same body. |
| Need to check NSSM env (e.g. `BOBIVERSE_NO_UPDATE`) | Do **not** run `nssm get ircBob AppEnvironmentExtra` and print the raw block - it includes `AGENTIC_IRC_PASSWORD` (FR #147). Print key names only (split on first `=`). See `bobiverse-fleet-ops` hotpatch rule. |
| `!startworker` NACKs `nobody is logged in` while `InstallRoot\run\startworker\tray.alive` is fresh | Frozen `bob-ear.exe` resolved install root via `Path(__file__).parent.parent` under `_MEIPASS` (often `C:\Windows\Temp\_MEI*`), so the ear looked for `Temp\run\startworker` (FR #2666 / PR #2671). Confirm `Start-Bob.ps1` exports `BOB_INSTALL_ROOT=$InstallRoot` before launch; restart `ircBob` so the env is picked up. Full frozen-aware resolve needs a rebuilt `bob-ear.exe` (`resolve_bob_install_root` / `--install-root`). Do not treat a fresh tray.alive under InstallRoot as proof the ear sees it until the root is correct. |
| `!startworker` NACKs `engine_stale` / queue stalled while `tray.alive` is fresh (UI thread spinning, log quiet) (FR #4136) | Hung-but-alive PS engine: `bob-tray.exe` HealEngine only used to restart exited engines. Tip: engine writes `engine.alive` after each startworker queue tick; HealEngine kills the engine tree when that stamp is stale (>120s) and restarts; `tray.alive` carries `engine_last_tick`; ear NACKs `engine_stale` when tray.alive is fresh but engine.alive is not. Rebuild `bob-tray.exe` + hotpatch `Watch-BobTray.ps1` / tip ear. Does not fix the UI-thread spin root cause. |
| Tray worker env differs from CLI (`C:\\Users\\...` doubled `BOB_*_HOME`, or unexpected `CURSOR_*`/`SAND_*`) | `Start-BobFleetTray` seat wrappers used to double backslashes in env assigns (FR #2669 / PR #2680). Confirm wrapper uses single-quoted path assigns and `hasDoubledEnv` rewrite; restart tray via `Start-BobFleetTray`. `bob-worker` `prepare_seat_child_env` merges `extra` then normalises `BOB_*` paths and scrubs `CURSOR_*`/`SAND_*` **after** the merge (FR #2683 / PR #2690) so a hostile overlay cannot reintroduce agent-host keys (needs rebuilt `bob-worker.exe` for the scrub path). |
| Blank PowerShell console steals focus every minute | **FR #3909:** `BobiverseTrayWatchdog` (and `BobiverseTray`) used `powershell.exe -WindowStyle Hidden` under LogonType Interactive — the console still appears until Hidden applies, and a slow `Get-CimInstance Win32_Process` probe kept it up for ~1 min. Installer now registers `conhost.exe --headless powershell.exe ...` (Win10 21H2+ / Server 2022), defaults the watchdog to every 5 minutes, and prefers `Get-Process bob-tray`. Re-run `Start-BobTrayInteractive.ps1` (or MSI upgrade) to rewrite the task; confirm Action Execute is `conhost.exe`. |
| `python -m pytest bob/tests` kills Grok Bot / grok.exe / every python|pwsh|node | **FR #2928:** `test_fr2669` used to `. 'Start-BobFleetTray.ps1'`, which ran `Invoke-BobSystrayTidy` (Stop-BobSystrayPriorAgents + Cleanup-OrphanAgents). Fixed: `Start-BobFleetTray.ps1` returns immediately when `$MyInvocation.InvocationName -eq '.'` (functions only). Until tip is on the box, deselect that test. `BobTrayStartWorker.ps1` is already function-only (safe to dot-source). |
| Crash hook: `UnicodeDecodeError: 'charmap' codec can't decode byte 0x9d` in `subprocess._readerthread` | **FR #3943:** Windows `text=True` without `encoding=` uses cp1252 strict; UTF-8 child stdout (byte `0x9d`) kills the reader thread. Ear-path helpers must use `encoding="utf-8", errors="replace"` (see `common/scripts/subprocess_utf8.py`). Needs rebuilt `bob-ear.exe` after the common tip lands. |
| Crash hook: `UnicodeEncodeError: 'charmap' codec can't encode character '\u2192'` in `info()` / outbox drain | **FR #4396:** Windows NSSM/console stdout often uses cp1252 strict; `irc_agent.info` printed outbox previews containing RIGHTWARDS ARROW and killed the outbox thread. `info()` now catches `UnicodeEncodeError` and re-prints with `errors="replace"`. Needs rebuilt `bob-ear` / service restart to land on a box. |
| Watch `-RepoRoot` is the install root; intake helper missing | Live `Watch-BobTray -RepoRoot` is `<ai root>\bob`, not `bob\tray`. Dot `tray\src\Private\Invoke-BobMustReportFailure.ps1` and `common\scripts\Report-BobRuntimeFailure.ps1` (flat `src\` / `scripts\` fallbacks) before claiming an intake report (MRB #5060 / harvest #5063). Do not park this under harvest/SKILL.md. |
| Digest webhook / timer fails with no GitHub issue | **FR #5050:** `trayDigestTimer` Write-BobIrcStatus catch must log and call `Report-BobRuntimeFailure` (intake, deduped). Ear/Jeeves crash-hook install failures also report. Remaining empty `catch { }` cleanup is a follow-up, not silent on this timer. |
