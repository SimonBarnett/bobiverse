# Bobiverse fuel-family logos (FR #6149)

These PNG badges under `bob/tray/assets/fuel-logos/` are **original Bobiverse artwork**
drawn for TipForm / Status fuel rows. They are stylized family markers (letter chips),
not official Cursor, xAI, OpenCode, or GitHub Copilot brand marks.

## Fallback

(`Cu`, `xAI`, `OC`, `Gh`) instead of an image.
