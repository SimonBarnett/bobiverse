# BOB-34 Agents > Jeeves models webhook

Agents > Jeeves reads the Jeeves object from the models webhook file.

Path: `BOB_MODELS_WEBHOOK_FILE`, or `run/models-webhook.json` under the install root.

The tray log cites `jeeves-models webhook model=... context=... effort=...` before the start. A document with no Jeeves object does not invent settings.
