2. **`NICK_RE` rejected hyphenated nicks** (`cm-oscar`) — `parse_seal_line` returned `None`, SEAL silently ignored on wire. Cause: `-` inside a character class formed a range `\-_`. **Fixed** `c6e9c53` (hyphen at end of class).

4. **AWS / Grok Bot box** — Libera requires SASL + verified NickServ email. Mode-1 must run from IONOS (or with SASL) until accounts exist.
5. **Windows `Start-Process` hello quoting** — `--hello "oscar online mode1"` can split into unrecognized args. Use single-token hello or argv array carefully.
