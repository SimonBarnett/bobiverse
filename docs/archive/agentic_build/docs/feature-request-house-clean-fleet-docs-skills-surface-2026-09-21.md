# Feature request: house-clean fleet docs, skills, and job surface

**Date:** 2026-09-21
**Repo:** https://github.com/SimonBarnett/agentic_build
**GitHub issue:** https://github.com/SimonBarnett/agentic_build/issues/89
**Raised by:** Simon (via originating agent review)
**UAT + hostile MRB owner:** Bob
**Build orchestrator:** Bob — `Start-BobBuild -Task git`

This repo is a **private legion**. Do not productise. Do not extract a generic module for strangers. Clean the house so Bob and workers load one truth.

## Problem

1. **Docs drift.** README, `agent_readme.md`, and `.grok/skills/grok-build-fleet/SKILL.md` disagree on:
   - machine ids (`dev1` vs `ce-priority-dev1`; flamingo present in some lists, missing from handover table)
   - IRC (Libera leftovers vs private Ergo `irc.ntsa.uk:6697` `#bobiverse`)
   - which script starts the loop (`Start-BobBuild -Task git` vs `Start-BobBuildLoop.ps1`)
   An agent that loads the wrong file will enqueue the wrong box.

2. **One module, four jobs.** `BobBridge.psm1` exports job control, fuel gates, tray RGB/hover, and IRC POINT helpers together. `Get-BobTrayHover.ps1` is tens of KB. Skills guess cmdlets.

3. **Deploy crumbs in source.** `tools/_Watch-Bobiverse-*.ps1`, `tools/_Watch-BobTray-*.ps1` are per-machine install output. They rot and confuse harvest.

4. **Skill overlap.** `bob-build-loop`, `bob-job-loop`, `cursor-mrb-dev`, `bob-hostile-mrb`, `Start-BobBuildLoop.ps1`, `Start-BobMrbHandoff.ps1` all describe pieces of the same PR → MRB → FIX transaction. Workers load two of them and fork the ritual.

5. **Merge authority is prompt-only.** PASS-nits means the MRB agent merges. That is the written policy. GitHub `main` is not protected by rules that match it (no required issue link, no block on FAIL labels).

6. **No job audit line.** After outbox there is no single record of fuel + model + machine + PR URL + MRB issue + merge SHA. Cost and blame live in tray hover and IRC POINT scraps.

7. **Secret denylist is assignment-shaped.** `Test-PromptSecrets` refuses `password=` / `XAI_API_KEY=` assignments and allows instructional mentions. Good. It will miss other forms (`export XAI_API_KEY …`, env files copied into a goal). Keep the instructional-mention pass; widen the refuse list in Test-Pack only.

## Ask

### 1. One canonical runbook

- README is the human + agent source of truth for machines, fuels, IRC, and the PR/MRB loop.
- `agent_readme.md` is a short handover that **must not invent** machines or hosts. Either generate it from README or make it a strict subset and add a Test-Pack check that the machine table in both files is the same set: `ionos`, `flamingo`, `marchhare`, `ce-priority-dev1` (plus any id that `config/fleet-registry.json` actually lists).
- Kill Libera / old flowchart text. IRC is Ergo `irc.ntsa.uk:6697` `#bobiverse` only.
- Clone-path guessing stays (this house), but list every live clone path next to the machine id in **one** table.

### 2. Skill map, not a new product

Do not invent a public SDK. Do this:

| Skill | Only job |
|---|---|
| `bob-spec-intake` | Park FR issue + `/docs` md |
| `bob-build-dispatch` | Write plan + `Start-BobBuild -Task git` |
| `bob-job-loop` | `Start-BobBuildLoop.ps1` retry + PASS-nits notify |
| `bob-hostile-mrb` / `cursor-mrb-dev` | Hand off MRB; FAIL → FIX; PASS-nits merges |
| `grok-build-fleet` | Start/monitor/stop; picker; heal watcher |

`bob-build-loop` becomes a pointer to the four rows above, or is deleted after copies in `~\.grok\skills` are reaped by `Reinstall-AgentSkills`.

### 3. Module export hygiene (no split-for-sale)

Keep one `BobBridge.psd1`. Change exports:

- Default / documented for agents: job + fuel + machine cmdlets already in `agent_readme.md`.
- Tray and IRC helpers may stay exported (tray scripts need them) but skills must not mention them except `bob-fleet-tray` and `bob-irc`.
- Add a Test-Pack list: agent-facing names vs tray-only names. Fail the pack if `grok-build-fleet` documents a tray paint cmdlet.

Do **not** publish `BobBridge.Jobs` as a separate product.

### 4. Remove or generate machine wrappers

- `tools/_Watch-*.ps1` are either generated by `Install-BobFleet` / `Install-BobIrc` into the local bridge home (not committed) or live under `tools/generated/` with a header `DO NOT EDIT`.
- Harvest must not copy them into skills.

### 5. GitHub rules that match the ritual (this repo only)

On `SimonBarnett/agentic_build`:

- Protect `main`: no direct push from workers; PRs only.
- Document (and if tokens allow, enable) that FAIL-labelled MRB must not merge; PASS-nits may.
- Workers still never push `main`. This FR does not give Cursor or Copilot UAT.

If org settings cannot be flipped from a worker, the plan is: write the intended rules in `/docs` and a checklist Bob ticks at UAT. Do not fake a passing protection check.

### 6. Job audit stamp

When a git task hits outbox (and again on PASS-nits merge), write one JSON or markdown line the tray and IRC can both read:

```text
jobId machine fuel model kind prUrl mrbIssue sha status
```

Reuse existing job files if they already have the fields. Do not add a second database.

### 7. Secrets — Test-Pack only

Extend fixtures: refuse assignment-like and `export VAR value` forms; still pass “Do not set or request XAI_API_KEY”. No new runtime product.

## Acceptance

1. One machine table shared by README and `agent_readme.md`; Test-Pack fails if they diverge from `config/fleet-registry.json` ids (allowing documented aliases only if listed in that JSON).
2. No Libera / “named cursor machine” language in README, `agent_readme.md`, or `grok-build-fleet`.
3. Skill table in README matches the map in §2; overlapping skills are stubs or gone.
4. `_Watch-*` either untracked or clearly generated; Test-Pack or harvest skips them.
5. Agent-facing export list is written down; tray cmdlets are not in `grok-build-fleet`.
6. Job outbox / merge path has the audit line fields (even if some are empty on Fake-Grok).
7. Test-Pack covers the extra secret fixtures and the machine-table check.
8. Commit + push on `work/<job>`. Hostile MRB on issue #89. Do not mark ready for human UAT until Bob passes.

## Non-goals

- Productising BobBridge or selling leftover Cursor / Grok quota.
- Unattended public IRC.
- Changing fuel order or model family regex unless a test proves drift.
- Letting the implementer MRB their own PR.
- WinRM, Windows service, SQL passwords in packets.
