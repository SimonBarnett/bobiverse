## What we learned (ops)

- `BobFleet-ionos` registered after logon never fires until `Start-ScheduledTask` (or next logon). Result `267011` = never ran.
- Default task `ExecutionTimeLimit` 72h would kill the infinite poll loop.
- Named Grok Bot hangs live in Temporal (`GROK_BOT_SEND_STATUS_PENDING` or ACCEPTED user echo with no later assistant `send-message`). UI bubbles can be optimistic; **Waiting to send** is PENDING. Transcript is source of truth. Interrupt does not always end the turn. Desktop restart does not cancel Temporal. RecreateSandBox (`preserveData` + `force`, `--agent` required) rotates the **shared** cloud box once; wait for the transfer toast / stable `podId` before any ping. Preferred ping is the Grok Bot UI. Do not Recreate per agent.
- `lastSeen` updates at tick start only. A live claimed `grok.exe` holds the loop.
- Sequential watcher: one running job, inbox waits.
- Human UI is a system tray icon (`Watch-BobTray.ps1`), not a blank PowerShell window. Flashes on ACTION_REQUIRED.
