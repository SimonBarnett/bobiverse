# bobiverse-airc

> **CAST IRON RULE - HARVEST AND FILE EVERYTHING (read this first, every time).**
> 1. ALWAYS harvest skills you learn and file EVERY issue / FR / bug / gap you find to the intake webhook in the
>    SAME turn. Never leave a finding unfiled, never "note it for later", never skip it because it is small.
> 2. File with the intake webhook (no secret or login needed; `POST https://irc.ntsa.uk/bob/v1/intake`; offline it is
>    queued locally and retried):
>    `.\scripts\Report-BobiverseIntakeIssue.ps1 -Repo SimonBarnett/bobiverse -Kind issue -Title "short title" -Body "what / where / evidence / fix"`
>    (`-Kind issue|fr|skill|harvest`; always pass an explicit `-Repo owner/name`).
> 3. BEFORE finishing ANY debugging session run the harvest step:
>    `.\scripts\Invoke-BobiverseHarvest.ps1 -Summary "what broke / what fixed it" -Lesson "one learned playbook line"`
>    then `.\scripts\Invoke-BobiverseHarvest.ps1 -Flush` to resend anything that was queued while offline.
> 4. Never put a token, password, SASL/NickServ secret, key or private hostname in a filing, a skill or a log.

Foundation: `bobiverse-fleet-ops` (shared ops/hotpatch/health) and `harvest` -> https://github.com/SimonBarnett/bobiverse

## Architecture

Service **`Airc`** (NSSM, tree `<ai root>\airc`) runs the Airc console: IRC nick **`<MachineId>_console`**.
**MachineId** is the canonical lowercase fleet id (`-MachineId` / `BOB_MACHINE_ID`).

| Piece | Where |
|---|---|
| Install root | `<ai root>\airc` (`scripts\`, `config\`, `logs\`, `assets\`, `.grok\skills\`, `VERSION`) |
| ConsoleHome | LocalSystem / MSI: `<ai root>\airc\home` (FR #3288; migrate off any `Users\<profile>` path). Never `C:\Users\Default\.airc` (FR #2355). |
| NickServ GUID | `<ConsoleHome>\console.password` (minted; not the Ergo PASS) |
| Ergo PASS | `<ai root>\airc\config\ergo.password` (Install copies; never invent) |
| Secret ACLs | `Protect-BobiverseSecretPath`: SYSTEM + Administrators only (`AreAccessRulesProtected`); no Users / Authenticated Users / installing-user (FR #3288). Install also deletes `Users\Default\.airc*`. **Tests (FR #3583):** never detect High-IL via `WindowsIdentity.Groups` (integrity SID absent there); use `WindowsPrincipal.IsInRole(Administrator)` - elevated read OK after ACL assert; Medium-IL / non-admin still requires `Get-Content` denied. |
| Logs | `<ai root>\airc\logs\*.log`, `<ConsoleHome>\*.log` |
| IRC | SASL on by default for reserved `<MachineId>_console` |

**Airc vs AircConsole:** bobiverse `Airc` (`<ai root>\airc`) != agentic_irc `AircConsole` (`<ai root>\airc-console`). One console per box: `Install-Airc` removes leftover `AircConsole` from SCM.

## Remote control

- Shell ergonomics: FR #75 (PowerShell default, `cmd:`, `psb64:`, `DONE id= exit=`).
- **Capabilities (FR #3287):** MSI props `AIRC_SHELL=off|operators`, `AIRC_JOBS`, `AIRC_UPDATE`, `AIRC_REQUIRE_ACCOUNT`, `AIRC_ACCOUNTS` -> `Install-Airc` / AppParameters / `config\airc.json` (upgrade-preserved with FR #1552). Fresh default `shell=off` (STATUS/ping only, else `DONE exit=126 shell-disabled`); upgrade of an existing Airc defaults `operators`. CLI: `--shell-mode` / `--shell off|operators`, `--jobs`, `--update`. Start log: `INFO capabilities shell=...`. **Authorisation (FR #3401 / #3639):** live control-channel status only - ops (+o) or half-ops (+h) or higher; `DONE exit=126 not-op` otherwise. No `operators.txt`, no `config\fleet-operators.txt` roster and no nick allow-list on any profile (the `AIRC_OPERATORS` property and `--operators` / `--operators-file` are accepted and ignored). Fleet and workstation answer DMs only and stay silent in channel; client also takes commands in the control channel. Auth waits for NAMES/366 and never authorises the console's own nick.
- **Crash-report opt-out (FR #3291):** C# tray parity FR #3328 / Install intake opt-out FR #3395 / local_only never-flush FR #3452. no-agent / `shell=off` writes `config\crash-report.json` `enabled=false` (also MSI `BOBIVERSE_CRASH_REPORT=0|local-only|no-log-tail`). Runtime: env `BOB_CRASH_REPORT` or that JSON; when disabled, crashes still spool under `%LOCALAPPDATA%\Bobiverse\crash-spool` and never POST intake/`gh` (Python `crash_report` and C# `CrashHook` for bob-about/status/tray). FR #3452: `local_only` / `error=local_only` spool stamps are dropped on later flush even when send is re-enabled. FR #3395: `Install-Airc` failure path also skips `Report-BobiverseIntakeIssue` when opt-out (local MSI log only; when allowed, passes `-Repo SimonBarnett/bobiverse`). **FR #3515 / #3584:** client keep-list retains `Report-BobiverseIntakeIssue.ps1`; outer `Install-Airc` catch and nested `Install-AircConsole` catch both call `Send-BobiverseAircInstallFailureIntake` (redacts title/body via `Redact-BobiverseCrashText`, mirrors `crash_report.redact`). **FR #3584:** `$script:AircInstallFailReported` — nested catch sets the flag before rethrow so the outer catch does not file a second intake. Start log: `INFO crash-report=off (...)`.
- **Command StdOut Unicode (FR #2580):** every PowerShell `-EncodedCommand` is prefixed so `$OutputEncoding` / `[Console]::OutputEncoding` are UTF-8 (no BOM); `cmd:` gets `chcp 65001`. Redirected powershell.exe otherwise defaults `$OutputEncoding` to ASCII and best-fits Greek/CJK (alpha->a, U+FFFD/`?`) before airc UTF-8-decodes capture.
- **Command StdErr CLIXML progress (FR #2641):** the same EncodedCommand preamble sets `$ProgressPreference = 'SilentlyContinue'` so redirected powershell.exe does not emit `#< CLIXML` / `Preparing modules for first use` on stderr for plain `Write-Output` (extra IRC flood + false StdErr). Terminating / `Write-Error` CLIXML is decoded to plain text by FR #2910. Frozen `airc.exe` needs rebuild/redeploy for the fix.
- **Command StdErr plain text (FR #2910 / #2918):** terminating errors / `Write-Error` still arrive as CLIXML on redirected hosts; `run_shell_request` decodes `<S S="Error">` payloads (unescape `_xHHHH_`) to plain StdErr, keeps the UTF-8/progress preamble on its own lines (no fused preamble leak), and rewrites `At line:N` by subtracting the preamble line count so offsets match the user script. Frozen `airc.exe` needs rebuild/redeploy.
- Driving-box helper: `scripts\Invoke-AircRemote.ps1` (FR #76) - `-SelfTest`, `-Outbox`, PUT chunking client-side.
- **ReplyFile wait (FR #1546 / PR #1560):** `Invoke-AircRemote -ReplyFile` prefixes `id=<8hex>` on Command/Cmd/Psb64, then polls `<bob home>\airc-replies.jsonl` until matching `DONE` (timeout exit 2). The bob ear appends `*_console` Query `out`/`err`/`DONE` PMs to that jsonl (see `bobiverse-bob-commands`). Never rely on a pre-written reply file alone. Overlapping remotes that reuse the same id can collide.
- **Long Command output / reconnect (FR #2612):** console Query replies go through an outbound queue that survives in-process `force_reconnect` and drains after handshake; graceful stop flushes `DONE exit=1` for in-flight shell ids. Hard process kill mid-emit can still drop the queue - prefer not to Restart-Service Airc during a live ReplyFile Wait; raise `-TimeoutSec` for 80+ line floods (~0.35s FLOOD_S per line).
- **Concurrent shells / busy (FR #2632):** `ShellJobRunner` queues one in-flight shell per Query nick plus up to `SHELL_PENDING_MAX` (8) waiting commands so two overlapping `Invoke-AircRemote -Action Command` calls both get a real DONE. Only a full pending queue fail-closes with `err ... busy: prior shell still emitting` + `DONE exit=1` (no hang / no lost DONE). `Invoke-AircRemote` also treats that busy DONE as retryable within `-MaxRetries`/`-TimeoutSec` (compat with older airc builds that always busy-failed).
- **MRB airc suite (FR #2655):** before PASS on an airc product PR, run the full `airc/tests` suite (not only the new FR file). `send_privmsg` stubs must accept `flood=` / `**kw` after #2652.
- **Stop flush before socket close (FR #2640 / #2649):** prepare_stop / stop interrupt paths enqueue DONE for in-flight **and** pending shell ids, drain the outbound queue **with flood=False** (no FLOOD_S gap between err and DONE - SCM was killing the socket in that 0.35s window), then close. `_stop_flushed` prevents finally from re-draining after sock=None (`stop-flush-send-err send: no socket`). While _stopping, _on_console_out enqueues only.
- **STATUS + Heard: strip (FR #2570 / #2575):** Status pins `id=<8hex> STATUS`; the console emits `out id=... seq=1 STATUS machine=...` then `DONE id=... exit=0` (same framing as shell so Invoke-AircRemote StdOut fills). Console `sanitize_console_operator_text` strips Halloy/bobtalk `@nick ... Heard:` wrappers before verb/shell routing (avoids PowerShell splat on `@machine_console`). **Footgun:** `-ReplyFile` ending in `.jsonl` that is **not** the ear's `home\airc-replies.jsonl` makes Wait poll an empty file - always use the ear path (or omit and let Resolve-AircRepliesJsonl pick it).
- Console NSSM logging (FR #1546): AppStdout/AppStderr under `<ai root>\airc\logs\airc-console.log` with rotate; DisplayName/Description expanded with the machine id (no literal `#{machine}`); service `info()` lines are ISO-UTC; keepalive PING logged at most once per hour via `info_keepalive`.
- Protocol sketch: `docs/airc-remote-control.md`. Ops: `docs/airc-ops.md`.

## Install, upgrade, rollback, hotpatch

See `bobiverse-fleet-ops`. Airc specifics: after MSI ensure `config\ergo.password`; re-run `Install-Airc.cmd -MachineId <id>` if NSSM is stale.
**Start-update policy (FR #3289 / #3393):** frozen `airc.exe` and `Start-AircConsole -ServiceMode` read `config\airc.json` `sync_from_repo` / `self_update`. **Fleet** fresh MSI default is **sync off** (unsigned `main` must not run as SYSTEM) and **self_update on** (sha256-checked release MSI). Log lines: `INFO sync-from-repo=off (config)` / `INFO self-update=on (config)`. MSI props `AIRC_SYNC_FROM_REPO=0|1` and `AIRC_SELF_UPDATE=0|1`; env `BOBIVERSE_SYNC_FROM_REPO` / `BOBIVERSE_SELF_UPDATE` / `BOBIVERSE_NO_UPDATE=1`. `Sync-BobiverseFromRepo -Product airc` also refuses when sync is off. Install locks the tree with `Protect-BobiverseInstallTree` (Users RX only).
**Bootstrap tools (FR #3290):** when `airc.exe` is present, `Install-Airc` skips `Install-BootstrapTools` (git/gh/Python/Node + pip) by default and logs `INFO bootstrap-tools skipped (airc exe; AIRC_INSTALL_TOOLS not set)`. Opt in with MSI `AIRC_INSTALL_TOOLS=1` or `-WithTools` / `-ForceTools`. Legacy (no exe) still bootstraps. bob/jeeves use `BOBIVERSE_SKIP_TOOLS=1`. Installed tools are listed in `%ProgramData%\Bobiverse\installed-tools.json`.
**Workstation profile / purge (FR #3292 / #3392 / #3393 / #3687):** `AIRC_PROFILE=workstation` or `AIRC_AGENT_LAYER=0` skips agent layer + skills (`INFO agent-layer skipped`). **FR #3687:** Pack moves those files into WiX `AgentLayerFeature` / `BobiverseAircAgentLayerFiles` with `Condition Level="0"` for client|workstation|`AIRC_AGENT_LAYER=0`, so msiexec never lays them (even when `Install-Airc.ps1` fails / PS 4.0 refuse). `Remove-BobiverseAircWorkstationAgentPayload` stays defence-in-depth only. The same profile defaults `self_update=false`, `shell=off`, `jobs=off`, `update=off`, `require_account=true`, and crash-report off unless each MSI/CLI property is set explicitly (no SYSTEM GitHub release MSI channel on client boxes). Fleet installs keep today's defaults. Manifest `%ProgramData%\Bobiverse\airc-install-manifest.json`. Uninstall fleet default keeps ConsoleHome (FR #1566); workstation / `AIRC_PURGE=1` removes ConsoleHome, config/logs/.git/.grok, `Users\Default\.airc*`, `ProgramData\Bobiverse\update\airc`, `ProgramData\Bobiverse\logs\install-airc.log`, and LocalSystem `%...\systemprofile\...\Bobiverse\crash-spool`.
**Client profile (FR #3401 / #3462 / #3511 / #3514 / #3582 / #3687):** `msiexec /i airc-x.y.z.msi /qn AIRC_PROFILE=client` - MSI `AgentLayerFeature` gate (FR #3687) excludes agent briefings/skills/launchers at Feature level (`Report-BobiverseIntakeIssue.ps1` stays on MainFeature), then **allow-list** tree via `Remove-BobiverseAircClientExtraPayload` (FR #3514: keep `airc\airc.exe`, `third_party\nssm`, `config\` for install-generated secrets only, `logs\`, `VERSION`/`BUILD.json`, and install/uninstall/start/recover + `Report-BobiverseIntakeIssue.ps1` / console host scripts only - workstation deny-list alone left Jeeves/Bob/docs; **FR #3582:** also delete `config\fleet-operators.txt` - client never reads the fleet roster), **full** remote shell/pipe/jobs, `auth_mode=irc_ops` (no `operators.txt`; authorise only live `+o`/`+h`/`+a`/`+q` in the control channel; deny `DONE exit=126 not-op`), control channel = registered `#<machine>` else `#<domain|workgroup>` (`INFO control-channel=... reason=registered-machine|domain-fallback`), `self_update=false` / `sync_from_repo=false` (FR #3462: both ignore prior fleet airc.json true unless MSI/CLI explicit), crash reports **on** (honour explicit `BOBIVERSE_CRASH_REPORT=off`), purge uninstall default like workstation. CLI: `--auth-mode irc_ops`. **FR #3511:** clear `ChannelMemberMap` on handshake / (re)JOIN and on console self-PART/KICK (`lost-control`  rejoin); refuse until NAMES/366 so stale `@`/`%` from offline PART/QUIT cannot keep SYSTEM shell.
**ACL fail-closed (FR #3394 / #3516 / #3554 / #3581 / #3652 / #3678):** `Install-Airc` locks `%ProgramData%\Bobiverse` with `-ProtectMode LogsOnly` (root + `logs\` only) and writes `install-begin` before that Ensure (FR #3652: default Full -Recurse walked `update\bob`/`update\jeeves` backups and hung ionos upgrades 55+ min). MSI log writes also use LogsOnly once per process (FR #3554). Env `BOBIVERSE_PROGRAMDATA_ROOT` redirects for tests. Early install locks `<ai root>\airc` **root-only** (no `-Recurse`); **one** Full `-Recurse -FailClosed` runs before Start-Service (FR #3678: two Full -Recurse + `takeown /R` passes cost ~12 min on ~5k items). Protect **SetOwner** Administrators on each Set-Acl; **takeown /A /R** only when `-Recurse` **and** the root is not already the protected target (FR #3516 / #3581 / #3678 - LogsOnly must not takeown /R ProgramData; upgrades skip takeown when already Admin/SYSTEM-owned). Purge allow-list bases are MSI/arg InstallRoot + trusted ConsoleHome (AppParameters / config\airc-install.json) - **never** manifest.install_root / manifest.console_home; drive-root prefixes refused (Test-BobiverseAircPurgePrefixIsSafe); every purge target passes Test-BobiverseAircPurgePathAllowed.

Self-update on start uses **`Update-BobiverseService.ps1`** (detached Apply - never inline msiexec in the live service) when `self_update` is on. Hotpatch = back up `<ai root>\airc`, copy changed scripts, `Restart-Service Airc` ONLY.
**Fleet wrapper (FR #1545 / PR #1561):** legacy NSSM entry `Start-AircConsole-Fleet.ps1` must delegate to `Start-AircConsole.ps1 -ServiceMode` so gated sync + self-update run (same opt-outs). Always pass `-ServiceMode` under NSSM. Use `$launchArgs` for the splat - never automatic `$args` (PR #1588).
**Upgrade AppParameters (FR #1552 / harvest #1583):** MSI upgrade/reinstall must read the **live** NSSM/service `AppParameters` first, then `airc-install.json` fallback, **before** any profile default. Never invent a new `ConsoleHome` when an identity already exists (keeps NickServ GUID / shop nick). Merged PR #1570 + docs #1575.
**Uninstall (FR #1566):** MSI `/x` runs `Uninstall-Airc.cmd` before RemoveFiles (`REMOVE="ALL" AND NOT UPGRADINGPRODUCTCODE`) to stop/remove service `Airc`; ConsoleHome secrets stay. Manual: `scripts\Uninstall-Airc.cmd`.

## Do not

- Run `Airc` and `AircConsole` together; invent an Ergo PASS; stamp UAT; put secrets on IRC; call retired `Check-BobiverseUpdate.ps1` for fleet ops.
