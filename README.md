# bobiverse

Fleet IRC product: single-file MSIs for **Jeeves** (Ergo + chair), **Bob** ears, and **airc** consoles.

| MSI | Service(s) | Nick |
|-----|------------|------|
| `jeeves-*.msi` | `BobIrcd` + `ircJeeves` | `Jeeves` |
| `bob-*.msi` | `ircBob` (+ tray + Watch-AgentHealth) | `Bob-{machinename}` |
| `airc-*.msi` | `Airc` | `{machinename}_console` |

Repo: https://github.com/SimonBarnett/bobiverse

See `docs/functional-spec.md` and `docs/vision.md`.
